## 💡 What This Folder Is For

The typefaces the marks, the diagrams and the graphics are set in, so anyone who
opens a source sees it as it was drawn: WOFF2 or OTF, with the licence beside
each family (`OFL.txt` for an Open Font License face).

Only fonts whose licence allows them to be redistributed belong here. A
commercial face is named in this log and stays out of the repository.
