## 💡 What This Folder Is For

The **social preview** a site shows when the repository is linked, set under
**Settings → General → Social preview**: a PNG or JPEG of 1280 × 640 pixels
under 1 MB, with what matters kept clear of the edges, since some sites crop
them. GitHub keeps only the upload, so its source and export live here, as
`social-preview.png`.

Beside it: the Open Graph cards a documentation site serves (`og-*.png`, 1200 ×
630), and the graphics a launch or an announcement is posted with. The marks
they are built from belong in [`../branding/`](../branding/README.md).
