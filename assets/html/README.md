## 💡 What This Folder Is For

GitHub shows a committed `.html` file as its source, never as a page, and serves
its raw copy as plain text. A page here is opened through a viewer that fetches
and renders it, or published with GitHub Pages.

Make each page self-contained: its CSS and its scripts inline, its images beside
it by a relative path, so it renders the same wherever it is opened. Name it for
what it shows (`theme-preview.html`), and give a README that should show it a
capture in [`../screenshots/`](../screenshots/README.md).
