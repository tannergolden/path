## 💡 What This Folder Is For

Wireframes, design comps and screens exported from a prototype: PNG at 2x or
PDF, named for the screen and its state (`checkout-empty.png`). The live design
file stays in its tool; link it in the screen's row.

Once a design ships, its captures belong in
[`../screenshots/`](../screenshots/README.md), and the mockup can go.
