## 💡 What This Folder Is For

Reserved, and holding nothing but this log until the project has a critical
path worth measuring. When it does, the benchmark scripts go here, pinned so
that any run can be reproduced on defined hardware, beside the results they
produce.

The budgets those runs defend are set in the fill-in
[Performance Benchmarks](../docs/templates/technical/benchmarks/Performance-Benchmarks.md)
standard, and each run is recorded with the
[Research Log](../docs/templates/Research-Log.md) template: environment, commit,
scenario, raw numbers, and the conclusion drawn.

This directory is **yours from the first commit**. Nothing upstream will ever
write to it or delete from it.
