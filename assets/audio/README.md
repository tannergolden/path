Sound the project presents itself with: a podcast clip, a trailer, a voice-over,
a sound designed for a demo. Lossless masters through Git LFS, and a compressed
copy (MP3 or Opus) for the page that links it.

Every spoken file has a transcript beside it, for the same reason an image has
alt text.
