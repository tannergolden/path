## 💡 What This Folder Is For

General project imagery: screenshots for the README, product shots,
illustrations. Logos and other identity artwork belong in
[`../branding/`](../branding/README.md), and figures embedded in documents in
[`../docs/`](../docs/README.md).

For a user-interface interaction or a command-line flow, prefer a short looped
GIF, under 5 MB, over a static screenshot. Build output and very large files
stay out, as the [assets guide](../README.md) explains.
