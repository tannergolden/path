## 💡 What This Folder Is For

Material made to be printed or handed out: a datasheet, a one-pager, a poster, a
sticker. Print-ready PDF or SVG with the bleed and the colour profile the
printer asked for, named for the piece and its size (`datasheet-a4.pdf`,
`sticker-3in.svg`).

The marks it is made from belong in [`../branding/`](../branding/README.md).
