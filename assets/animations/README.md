## 💡 What This Folder Is For

GitHub plays a GIF wherever an image goes, so a short looped demo of a command
or an interaction lives here: a few seconds long and under 5 MB.

Keep what it was made from beside it, an asciinema `.cast` or a VHS `.tape`, so
the next version is recorded again rather than edited by hand. A demo longer
than a loop belongs in [`../video/`](../video/README.md).
