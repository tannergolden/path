## 💡 What This Folder Is For

The [Markdown Kit](https://github.com/tannergolden/markdown) draws these on
every run of the page's stub, from `.github/markdown.yaml`: the header and the
footer, each by day and by night, wide and narrow for a phone, and still for a
reader who asks for less motion, and the link buttons under the footer. Until a
stub calls the kit, this folder holds only its README.

**The kit owns the SVGs, not the folder.** It redraws them on every run and
takes away any it no longer draws, and leaves every other file here alone, this
README included. Change `.github/markdown.yaml` and let it redraw: a hand-edited
SVG is overwritten on the next run.
