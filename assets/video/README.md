## 💡 What This Folder Is For

GitHub plays a video in a README only when it was uploaded through the editor,
never from a committed file. A video here is the master, and the page links to
where it plays: the uploaded copy, a release asset or a video host.

Video is large. Track it with Git LFS, set up in `.gitattributes` before the
first file is committed, or keep only the link, in this log.
