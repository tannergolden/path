## 💡 What This Folder Is For

Photographs: the hardware the project runs on, a setup, the team, an event. JPEG
or WebP, resized to the largest size a page shows (2000 pixels on the long side
is plenty), with the metadata stripped, since a photo's EXIF can carry where it
was taken.

A person in a photograph has agreed to be in this repository. Credit the
photographer and the licence in the photo's row.
