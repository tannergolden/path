## 💡 What This Folder Is For

The [Markdown Kit](https://github.com/tannergolden/markdown) draws the trophy
case here when `trophies:` is on in `.github/markdown.yaml`: the tiered
trophies, the level card and the next-up card, and every achievement in
`achievements/`, each by day and by night. Until a stub calls the kit, this
folder holds only its README.

**The kit owns the SVGs, not the folder.** It redraws them on every run and
takes away any it no longer draws, and leaves every other file here alone, this
README included. Change `.github/markdown.yaml` and let it redraw: a hand-edited
SVG is overwritten on the next run.
